# 变化播客工作流

**主题**：变化——AI 的变化、年龄的变化、身份的变化。
**目的**：减少焦虑。每期把一种变化拆成具体场景，讲真实的人怎么经历它，留下一个今天就能做的小动作。

```
Task Progress:
- [ ] 1. 选题：属于哪种变化（ai / age / identity），听众此刻最焦虑的点是什么
- [ ] 2. 写大纲：3–4 个主问 + 穿插问题 + 事实锚点（只给主持用）
- [ ] 3. 每位嘉宾写答题卡（见下方模板），录前一天交换阅读
- [ ] 4. 录前 20 分钟对稿：只对结论和例子，不对台词
- [ ] 5. 录制（按「录制规则」）
- [ ] 6. 转写 → 剪辑决策表 → 渲染（见「剪辑流水线」）
- [ ] 7. 生成成片页、更新 episodes.json
- [ ] 8. 复盘：按三个问题打分，写进成片页
- [ ] 9. 提交并推送 main（Pages 才更新）
```

## 一、录前：答题卡（解决「乱」和「没例子」）

第一期最大的问题是很多回答边想边说，绕了一圈才落到观点；而且事实多、例子少，听起来像说教。所以每个主问，每位嘉宾录前写一张卡：

```markdown
### 主问 X：<问题原文>

一句话结论（≤20 字）：
三步链条：
  现象：我看到了什么
  原因：我认为是因为什么
  所以：这对听众意味着什么 / 可以做什么
例子（五要素：什么时候 / 在哪 / 谁 / 冲突 / 结果）：
  ……
我不确定的地方（留给对方追问）：
交棒句：「这点在 <对方岗位> 那边是不是不一样？」
```

检查标准：
- 链条里哪一步写不出一句话，说明还没想透，录前补，不要现场想。
- 没有例子的结论不上节目。事实和数据只作锚点，由主持一句带过。
- 避免「大家都应该」「你必须」「未来一定」，换成「我当时是这么做的」。

第一期可以当样板的例子：
- 「宽泛目标丢给 AI，两天白干，周三拿张纸自己画逻辑链再交给它」——冲突和结果都很具体。
- 「带应届生：指标口径说清楚时和 AI 配合很好，开放命题就失控」——一个人、两种情况的对照。

## 二、录中：录制规则（解决「衔接与打断」）

**角色分工**
- 主持：只做三件事——计时、拉回主线、讲得太抽象时要例子。不发表长观点。
- 嘉宾：每次发言先说结论，单次不超过 90 秒；说完用交棒句递话。

**打断只允许三种**
1. 要例子：「具体是哪一次？」
2. 复述确认：「你的意思是……对吗？」
3. 拉回主线：「我们先回到提效这件事。」

**打断时机与频率**
- 等对方说完一个完整句子再接，不在逻辑链中间插话。
- 每个主问，每人最多主动打断 2 次。
- 想到第二个问题先记在纸上，不要一次抛两个问题（第一期就出现过问了两个、第二个没问出来）。
- 同时开口时，后开口的人说「你先」，不要「对，我说 / 你说完了吗」来回拉扯。

**节奏**
- 一个主问 8–12 分钟。超过 12 分钟，主持喊小结：「用一句话总结一下？」
- 一人连续讲超过 3 分钟（第一期模型段约 10 分钟），主持插一句复述或要例子，把话递给另一位。

## 三、录后：剪辑流水线

```bash
# 1. 转写（faster-whisper，带词级时间戳，68 分钟约 10 分钟）
python3 scripts/transcribe.py _work/<slug>/raw.m4a _work/<slug> small

# 2. 写剪辑决策表 edits/<slug>.json
#    cuts: 口误、重复起头、抢话、绕圈论述；每条写明 why
#    chapters: 用原始时间或 find 文本定位
#    glossary: 转写同音错字校正（Cloud→Claude 等）

# 3. 渲染（静音压缩 + 单声道 + 降噪 + 压缩 + −16 LUFS，约 3 分钟）
python3 scripts/edit_episode.py edits/<slug>.json _work/<slug>/out

# 4. 生成网页数据（章节 + 校正后的转写稿）
python3 scripts/build_episode_data.py edits/<slug>.json _work/<slug>/out
cp _work/<slug>/out/<slug>.mp3 docs/audio/
```

剪辑原则：
- 只删口误、卡壳、重复和明显绕圈，不改变观点；两人观点不同的地方保留。
- 每处剪辑点用转写回听验证，确认没切掉半个字。
- `_work/` 与原始录音不入库；成片 mp3（64 kbps 单声道）放 `docs/audio/` 供网页播放。

## 四、复盘：每期三问

成片页最后写「本期复盘」，每个问题列出具体时间点和下期改法：

1. **链条**：有没有边想边说、一次两问、长段无小结？
2. **例子**：每个主问是否至少有一个五要素例子？事实是否落到了亲身经历？
3. **衔接**：打断是否属于三种合法打断？有没有同时开口、长独白不交棒？

## 索引字段

**series.json**：`id`（ai / age / identity）、`title`、`short`、`kind_label`、`status`（active / planned）、`interval`、`theme`、`cover_accent`

**episodes.json**

| 字段 | 说明 |
|------|------|
| `id` / `slug` | 稳定标识，如 `bian-ep01-ai` |
| `series` | `ai` / `age` / `identity` |
| `episode` | 全站统一编号，按发布顺序 |
| `status` | `outline` \| `draft` \| `edited` \| `published` |
| `outputs.outline` | 成片页或大纲页（相对 `docs/`） |
| `outputs.audio` | 成片音频（相对 `docs/`） |
| `outputs.data` | 章节 + 转写 JSON |
